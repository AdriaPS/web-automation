# ⚙️ Web Automation
This is a real‑world web automation project focused on interacting with dynamic websites using Python.
In this case I've used Python and Playwright to generate a Robot to be able to shop automatically for items, using scraping tecniques to get the items from the website so the Playwright Browser is able to click and/or fill the information on the proper elements of the web page.

# 🚀 Features
- Browser robot (Chromium based browser) using Playwright library.
- Encryption helpers to be able to encrypt and decrypt plain passwords to Base64 RSA keys (both private and public keys) using Cryptograph.
- File manipulation to extract data of the user from a .txt file.
- Page navigation through multiple web pages.
- Config dataclass to store data and use it through the project.
- Using Logging library to be able to log the errors or information during the execution of the application.
- Generate a requirements file to be able to export the libraries used and install them to be used locally on a user machine.

# 📦 Tech Stack
- **Python** - Main programming language.
- **Playwright** - To create the (chromium) Browser to be able to navigate through the web page.
- **Cryptograph** - To encrypt and decrypt the passwords to keep the user information safe.
- **Logging** - To generate logs from the application.
- **Path** - To generate or handle files such as the Logger files.
